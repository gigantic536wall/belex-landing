## 🚀 Как выложить сайт на GitHub Pages, чтобы его могли открыть другие люди

Проект изначально оптимизирован для GitHub Pages: в `vite.config.ts` указан `base: './'`, что гарантирует корректную загрузку всех стилей, скриптов и изображений в любом репозитории.

### Способ 1: Автоматический деплой через GitHub Actions (Рекомендуемый)

В проект уже добавлен готовый файл `.github/workflows/deploy.yml`.

1. **Создайте репозиторий на GitHub**:
   - Перейдите на [github.com/new](https://github.com/new)
   - Введите имя репозитория, например: `belex-landing`
   - Выберите тип **Public** (Публичный)
   - Нажмите кнопку **«Create repository»**

2. **Загрузите проект в репозиторий**:
   Выполните в терминале папки проекта:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of belex landing"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/belex-landing.git
   git push -u origin main
   ```

3. **Включите GitHub Pages**:
   - В вашем репозитории на GitHub перейдите в **Settings** (Настройки вверху) -> слева выберите раздел **Pages**
   - В блоке **Build and deployment** в поле **Source** выберите: **GitHub Actions**
   - Через 1–2 минуты страница обновится, и вверху появится ссылка на ваш сайт:
     `https://<ваш-логин>.github.io/belex-landing/`

---

### Способ 2: Быстрая ручная публикация через пакет gh-pages

1. Соберите проект:
   ```bash
   npm run build
   ```
2. Опубликуйте папку `dist`:
   ```bash
   npx gh-pages -d dist
   ```
3. В настройках репозитория (`Settings` -> `Pages`) выберите ветку `gh-pages` и сохраните.
